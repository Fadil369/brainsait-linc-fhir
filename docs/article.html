Bridging Edge Intelligence with Enterprise Healthcare — Bilingual, Agentic, FHIR‑Native

BrainSAIT is a production‑ready, edge‑computing AI platform that unites Cloudflare Workers AI with InterSystems IRIS. It delivers real‑time clinical reasoning, automated workflows, and patient‑centric insights — validated by a perfect 60/60 technical score and built for the Saudi healthcare ecosystem (NPHIES, Arabic/English, Saudi National ID validation).

1. Strategic Vision & Core Pillars

In modern healthcare, a critical gap exists between legacy clinical data (stored in robust systems like InterSystems IRIS) and agile, agentic reasoning powered by LLMs. BrainSAIT closes this gap by moving from passive data repositories to Agentic FHIR — where AI actively reasons over patient data, anticipates clinician needs, and executes administrative tasks without manual triggering.

2. Technical Architecture

Edge Layer (Cloudflare)

  • Workers AI – Llama 3.2‑3B‑instruct (optimised for structured JSON generation)
  • D1 Database – lightweight, distributed SQL storage for FHIR resources
  • Benefit – Near‑instantaneous inference even at peak volume

Core Layer (InterSystems IRIS)

  • Production classes – BrainSAIT.Production.MasterUnified
  • Responsibilities – Long‑term clinical state, workflow orchestration, audit trail
